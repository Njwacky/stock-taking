# Stock Usage Tracking - Quick User Guide

## 🎯 What is This?

The Stock Usage Tracking system allows you to **log your stock usage and request deletion of kits even when supervisors are not around**. Once approved by an admin, the stock is automatically deleted from the system.

---

## 👤 For Regular Users

### How to Log Stock Usage

1. **Click "Track Usage"** in the navigation menu

2. **Fill out the form:**
   - **Clock Number** - Your registered clock number (must match your account)
   - **Kit Type** - Select the type of kit you used
   - **Quantity Used** - How many items you used
   - **Purpose** (Optional) - Why you used the stock (e.g., "Assembly line", "Repair work")
   - **Feedback** (Optional) - Any comments about the stock quality or issues

3. **Click "Submit Usage"**

4. **Wait for approval** - Your request will be reviewed by a supervisor/admin

5. **Check status:**
   - 🟡 **Pending** - Waiting for review
   - 🟢 **Approved** - Approved, stock will be deleted
   - 🔵 **Completed** - Stock has been deleted
   - 🔴 **Rejected** - Request was rejected

### View Your History

- Click **"View Full History"** in the sidebar on the tracking page
- Or go to the tracking page and scroll down to see recent usage

---

## 👨‍💼 For Admins/Managers

### Review Pending Requests

1. **See notifications:**
   - Badge on "Track Usage" menu shows pending count
   - Alert box on tracking page shows pending requests

2. **Click "Review Pending"** or go to History page

3. **Filter by status:**
   - Select "Pending Review" to see only pending requests
   - Filter by user if needed

4. **Review each request:**
   - Click "Review" button
   - See user details, quantity, feedback
   - Add admin notes if needed

5. **Make decision:**
   - **Approve & Delete Stock** - Automatically deletes/reduces stock
   - **Reject** - Denies the request

### What Happens When You Approve?

✅ The system **automatically**:
- Deletes the kit if all quantity is used
- Reduces the kit quantity if partial usage
- Updates the usage status to "Completed"
- Logs the action for audit trail

**You don't need to manually delete anything!**

## ❓ Common Questions

**Q: Why do I need to enter my clock number?**  
A: For verification and audit purposes. It must match your registered clock number.

**Q: What if I made a mistake?**  
A: Contact an admin immediately. They can reject the request before approval.

**Q: Can I delete stock without supervisor approval?**  
A: No, all deletions require admin/manager approval for security and audit purposes.

**Q: What happens if the kit doesn't exist?**  
A: The system will log the usage for records, but won't delete anything. Admin will see a warning.

**Q: How long does approval take?**  
A: Depends on admin availability. Admins receive notifications about pending requests.

**Q: Can I see all my past usage?**  
A: Yes! Go to "Track Usage" → "View Full History"

## 🚨 Troubleshooting

**Problem: "Clock number does not match your account"**  
- Solution: Enter the exact clock number registered in your account
- Contact admin if you need to update your clock number

**Problem: Can't find my kit type**  
- Solution: Contact admin to add the kit type to the system

**Problem: My request is stuck in "Approved" status**  
- Solution: Wait a moment and refresh. If still stuck, contact admin for manual processing
