┌──────────────────────────────────────────────────────────────────────┐
│                         HOW TO TEST PWA                              │
└──────────────────────────────────────────────────────────────────────┘

🖥️  DESKTOP TESTING (Chrome/Edge):

   1. Start server:
      > python manage.py runserver

   2. Open browser:
      > http://localhost:8000

   3. Open DevTools (F12):
      → Application tab
      → Check "Manifest" section
      → Check "Service Workers" section

   4. Install the app:
      → Look for install icon in address bar (⊕)
      → Click "Install"
      → App opens in standalone window

   5. Test offline:
      → DevTools → Network tab
      → Select "Offline"
      → Reload page
      → Should show offline page or cached content


📱 MOBILE TESTING (Android):

   1. Deploy with HTTPS (required):
      → Use ngrok: ngrok http 8000
      → Or deploy to production server

   2. Open in Chrome Mobile:
      → Visit your HTTPS URL
      → Tap menu (⋮)
      → Select "Install app" or "Add to Home Screen"

   3. Test offline:
      → Enable airplane mode
      → Open installed app
      → Should work with cached content


🍎 iOS TESTING (iPhone/iPad):

   1. Open in Safari:
      → Visit your URL
      → Tap Share button
      → Select "Add to Home Screen"

   Note: iOS has limited PWA support
   → No background sync
   → No push notifications
   → Limited service worker features

┌──────────────────────────────────────────────────────────────────────┐
│                         SERVICE WORKER STRATEGIES                    │
└──────────────────────────────────────────────────────────────────────┘

📄 HTML PAGES:
   Strategy: Network First
   → Try network, fallback to cache
   → Show offline page if no cache

🎨 STATIC ASSETS (CSS, JS, Images):
   Strategy: Cache First
   → Serve from cache if available
   → Fetch from network if not cached

🔌 API REQUESTS:
   Strategy: Network First
   → Try network, fallback to cache
   → Return offline error if no cache


┌──────────────────────────────────────────────────────────────────────┐
│                         CUSTOMIZATION                                │
└──────────────────────────────────────────────────────────────────────┘

🎨 CHANGE APP NAME:
   Edit: static/manifest.json
   {
     "name": "Your App Name",
     "short_name": "AppName"
   }

🌈 CHANGE THEME COLOR:
   Edit: static/manifest.json
   {
     "theme_color": "#your-color",
     "background_color": "#your-color"
   }

   Also update: stockT/templates/base.html
   <meta name="theme-color" content="#your-color">

🖼️ CHANGE ICONS:
   1. Replace images in static/images/
   2. Or run: python generate_pwa_icons.py
   3. Collect static: python manage.py collectstatic --noinput

⚡ CHANGE CACHE STRATEGY:
   Edit: static/sw.js
   → Modify fetch event handlers
   → Change CACHE_NAME for new version

│                         TROUBLESHOOTING                              │
└──────────────────────────────────────────────────────────────────────┘

❌ SERVICE WORKER NOT REGISTERING:
   → Check HTTPS (required except localhost)
   → Verify sw.js is accessible
   → Check browser console for errors
   → Clear cache and retry

❌ MANIFEST NOT LOADING:
   → Validate JSON syntax
   → Check file accessibility
   → Run collectstatic
   → Clear browser cache

❌ ICONS NOT SHOWING:
   → Regenerate: python generate_pwa_icons.py
   → Collect static: python manage.py collectstatic
   → Clear cache
   → Uninstall and reinstall app

❌ OFFLINE PAGE NOT WORKING:
   → Check /offline/ URL works
   → Verify template exists
   → Check service worker caches it
   → Clear service worker

❌ INSTALL PROMPT NOT SHOWING:
   → Check all PWA criteria met
   → Try different browser
   → Check if already installed
   → Clear browser data
