│                         QUICK START GUIDE                            │
└──────────────────────────────────────────────────────────────────────┘

FOR SUPERADMINS:

1. LOGIN AS SUPERADMIN
   → Must have is_superuser=True

2. ACCESS MANAGEMENT
   → Scroll to footer
   → Click "Manage Footer" link
   → Or go to: /footer/contacts/

3. ADD CONTACTS
   Example - Email:
   ┌─────────────────────────────────────┐
   │ Contact Type: Email                 │
   │ Label: Support Email                │
   │ Value: support@company.com          │
   │ Order: 0                            │
   │ Active: ✓                           │
   └─────────────────────────────────────┘

   Example - Facebook:
   ┌─────────────────────────────────────┐
   │ Contact Type: Facebook              │
   │ Label: Our Facebook Page            │
   │ Value: facebook.com/company         │
   │ Order: 1                            │
   │ Active: ✓                           │
   └─────────────────────────────────────┘

   Example - Phone:
   ┌─────────────────────────────────────┐
   │ Contact Type: Phone                 │
   │ Label: Customer Service             │
   │ Value: +1234567890                  │
   │ Order: 2                            │
   │ Active: ✓                           │
   └─────────────────────────────────────┘

4. MANAGE CONTACTS
   → Edit: Update information
   → Toggle: Activate/deactivate
   → Delete: Remove permanently
   → Reorder: Change order numbers

┌──────────────────────────────────────────────────────────────────────┐
│                         TROUBLESHOOTING                              │
└──────────────────────────────────────────────────────────────────────┘

❌ FOOTER NOT SHOWING
   → Add at least one active contact
   → Clear browser cache (Ctrl+F5)
   → Run: python manage.py collectstatic

❌ CAN'T ACCESS MANAGEMENT
   → Must be superadmin (is_superuser=True)
   → Regular admins cannot access
   → Check user permissions in database

❌ CONTACTS NOT DISPLAYING
   → Check "Active" checkbox is enabled
   → Verify contact was saved
   → Refresh page
   → Check browser console for errors

❌ LINKS NOT WORKING
   → Check value format
   → Email needs @ symbol
   → Phone needs + and country code
   → Websites need full URL
